# 数值优化方案调研

> 版本：v0.1 ｜ 状态：调研草稿（2026-08 联网检索）
> 目的：为「袖里乾坤」的气运流转、成长曲线、掉落概率、经济平衡挑选可行的数值方案。

---

## 1. 我们的数值对象

| 数值对象 | 说明 |
|----------|------|
| 气运流转速度 | `基准值 × 倍率 × 活跃度因子`，三者都要定曲线 |
| 角色强度 | 资质/修炼/秘籍/装备/丹药 的成长曲线 |
| 闯关难度 | 各地区/难度/Boss 的强度曲线 |
| 盲盒掉落 | 秘籍/装备/丹药的稀有度概率 |
| 经济 | 钱币/灵石/内力/声望 的产出源与消耗槽 |

---

## 2. 候选方案（5 个，可组合）

### 方案 A：经典指数曲线公式（最主流）

- **公式**：`数值 = base × rate^n`（n 为等级/层数），挂机游戏的核心是「指数增长」。
- **适用**：升级成本、成长曲线、地区难度、气运流转基准值。
- **优点**：简单成熟、易调参、玩家体验熟悉。
- **做法**：把 base/rate 抽成**参数表**（不散落在代码里），用 Python/Excel 拟合调参。
- **参考**：多数放置游戏（Cookie Clicker、Adventure Capitalist 等）都用指数/多项式阶梯曲线。

### 方案 B：保底机制（Pity System）——**不采用（已决定：盲盒无保底）**

- **公式**：基础概率 + **软保底**（到阈值后每抽概率递增）+ **硬保底**（N 抽必出）。
- **适用**：盲盒稀有度、Boss 掉落、秘籍随机获取。
- **优点**：平滑「脸黑」体验，保证长期有正向反馈。
- **参考**：原神式抽卡（软保底 74 抽起概率递增、硬保底 90 抽）；10 连保底模型。

### 方案 C：Faucet-Sink 经济模型（水龙头-水池）

- **思路**：明确每种资源的**产出源（faucet）**与**消耗槽（sink）**，保持产出≈消耗，防通货膨胀。
- **适用**：钱币/灵石/内力/声望的整体平衡。
- **工具**：Machinations.io 或 Python 建模 + 模拟。
- **参考**：Lostgarden「value chains」、game economy design 标准方法。

### 方案 D：数值模拟器 + 回放测试

- **思路**：写一个「虚拟玩家」模拟器，跑 N 次完整流程，统计成长曲线、通关时间、经济健康度。
- **适用**：整体数值 sanity check、发现「卡点/爆炸」。
- **优点**：调参有依据，可自动化回归。
- **做法**：Python 脚本模拟「挂机→闯关→掉落→升级」循环，输出曲线图。

### 方案 E：反推参考（逆向成功案例）

- **思路**：采集 TBH / 导师模拟器等成功放置游戏的数值，用 Excel/脚本**反推公式**作为起点。
- **优点**：起点靠谱，少走弯路。
- **适用**：成长曲线、掉落率的初始猜测。

---

## 3. 初步建议

**组合方案：A + C 打底，D 做验证，E 做起点参考（B 保底不采用）。**

1. **先反推（E）**：参考 TBH/导师模拟器，定一套初始数值。
2. **用公式（A）**：把成长/成本/难度都写成 `base × rate^n` 的参数表。
3. **平衡经济（C）**：列出钱币/灵石的 faucet-sink 表，保证有消耗。
4. **模拟验证（D）**：写模拟器跑通，看曲线是否平滑、有无卡点。

---

## 4. 已确定决策

1. **成长节奏**：约 **100 小时**投入 → 打造成一个「比较 ok」的门派（核心成长曲线按 ~100h 设计）。
2. **后期内容**：100h 之后是**皮肤等与强度无关**的内容（长尾 / 外观收集）。
3. **盲盒无保底**：不做软/硬保底，纯概率掉落（方案 B 不采用）。
4. **数值存放**：用 **JSON 参数表**（方便后续调参）。
5. **100h 节奏分段**：0-20h 入门 / 20-60h 成长 / 60-100h 成型。
6. **经济通胀**：采用**温和通胀**（后期单位产出与物价同步变大，保持资源相对稀缺）。
