> 版本：v0.6 ｜ 状态：草稿（用户故事对齐完成，待数值/系统细节）
> 说明：本文档聚焦游戏设计层（用户故事 + 玩法场景），暂不涉及技术平台选型。

## 1. 游戏概述

袖里乾坤（掌中小世界）是一款借鉴 **Taskbar Hero** 的挂机（放置）游戏，用**肌电手环（EMG）**把「工作时的手部活动量」变成游戏增益。

- **中文名**：袖里乾坤（副题：掌中小世界）。
- **输入设备**：唯理科技肌电腕带（**sEMG 肌电 + IMU 惯性测量**，支持 SDK），**单手腕佩戴（默认左手）**。
- **核心目标用户**：长期对着电脑工作的**办公族**与**程序员**（整天打字、点鼠标）。
- **核心规则**：**手部活跃度越高 → 增益越好**；**手环连接是 bonus，不是必须**——不戴手环也能玩（键盘输入仍是活跃度来源）。
- **气运流转速度模型**：`气运流转速度 = 基准值 × 倍率 × 活跃度因子`。**基准值**随玩家成长提升（新手慢、pro 快）；**倍率**由技能/门派升级提供（乘算）；**活跃度因子** = 操作速度 + 手腕输入频率（肌电，默认左手，封顶）。

**最终玩法定位（已定稿）**：

- **主线「袖里乾坤」**：玩家是**袖中藏着一方迷你江湖的世外高人**。袖中世界里住着一群**生成式 AI 侠客**（类斯坦福小镇 Smallville：有记忆、有故事、有社交），他们自主修炼、闯荡、切磋，结缘结怨、恩怨情仇。**手部活跃度 = 内力 / 真气**，供能越高，江湖越兴盛、侠客越强、奇遇越多、奖励越好。
- **新手教程「新手门派」**：玩家先在一个小门派里学习基础循环（手部活跃度 → 内力供能 → 修炼 → 盲盒）。完成教程后进入**默认的上帝视角（闯关视角）**，门派成为江湖的一部分。
- **正魔两道**：门派分**正道 / 魔道**两条路线；技能分**通用技能（可直接购买）**与**稀有秘籍（随机掉落、一次性、可交易）**，再投入门派资源升级。
- **挂机形态**：**桌宠式**常驻桌面角落/任务栏（类似 Codex 桌宠），不打断工作流，工作间隙瞄一眼即可。
- **手环状态显示**：桌宠上有个**连接指示灯**——佩戴连接时**亮**，不佩戴时**灰色**，让玩家知道 bonus 是否生效。
- **玩家角色**：**观察者 + 经营者**——平时观察侠客自主演化，同时管理**门派资源**（类技能系统）做轻度经营。
- **交互方式**：**鼠标主要用于菜单操作**（开箱、交易、查看、管理门派资源/技能），核心演化由侠客自主进行；肌电手环为辅助增益；无手环也能正常玩。
- **闯荡江湖**：**主角与招募的 NPC 组队自动闯荡练级**（**阵容最多 3 人，含主角**；江湖分**地区与难度**），历练结果受**角色强度**影响，产出盲盒/奇遇/江湖轶事；各地区深处有 **Boss**，由玩家用**鼠标选择要挑战的关卡**（战斗自动进行）。
- **奖励与经济**：奖励分**两类**——**累计收益**（钱币/门派资源挂机自动积累）与**盲盒奖励**（历练/Boss 概率掉落，需查看并手动开启，开出秘籍、装备、丹药）。**通用物品在钱币商城购买，稀有物品（稀有秘籍、带特殊词条的装备）在真实市场交易**。
- **游戏目的（双目标）**：① **成为武林高手**（个人修炼变强）；② **维护一个一流门派**（经营袖中江湖的门派）。长任务中手部活跃度越高，收益与奖励越好（工作越投入，游戏收益越好）。

### 1.1 游戏目标与系统开放顺序

**建设目标（双目标）**：

1. **个人目标**：成为武林高手——玩家自身通过「手部活跃度 → 内力 → 修炼」不断变强。
2. **门派目标**：维护一个一流门派——经营袖中江湖的门派（招募侠客、升级技能、产出与交易）。

**系统开放顺序（新手引导，逐步开放）**：

1. **人物设定**：开局选择基本人物（**男 / 女**），以**落魄身份**起步（无名小卒 / 衰败门派）。
2. **世界观介绍**：介绍袖中江湖的起始设定与背景。
3. **如何修炼变强**：学习「手部活跃度 → 内力 → 修炼」的核心循环。
4. **主要打关流程**：学习闯荡江湖（地区/难度）与 Boss 战。
5. **建设目标**：明确「成为武林高手 + 维护一流门派」双目标，再逐步开放盲盒、市场、正魔道选择等系统。

### 1.2 世界观设定（草案）

**起源 · 袖里乾坤**

相传上古有一门失传绝学「**袖里乾坤**」：修成者能在袖中开辟一方天地，袖中日月自转、生灵自生。此界时间与外界不同步——外界之人「运功」（动手劳作）时，内力会化作「**气运**」，推动袖中世界演化。

**玩家身份**

玩家是这门绝学的**落魄传人**：初登场时无名无派，袖中只有一片衰败的江湖废墟。**而这门「袖里乾坤」本身，就是玩家的金手指**——别人练武靠苦修，玩家靠「劳作」就能运转一方世界、培养侠客、收获奇遇。玩家在现实中每一次打字、点击，都是「运功」，内力化作气运，世界随之复苏。

**袖中江湖**

袖中世界是一方迷你江湖，有山川门派、有侠客游走。侠客们有记忆、有性情，会自主修炼、闯荡、切磋，结缘结怨、恩怨情仇。玩家是「袖中世界的**观察者与守护者**」。

**正魔两道**

江湖分**正道**与**魔道**两派：

- **正道**：名门正派（少林、武当、峨眉之属），中正平和、根基扎实、进度稳健；优势在于**声望累积快、正派侠客亲和、产出稳定**。
- **魔道**：旁门左道（魔教、邪派之属），剑走偏锋、速成凶险；优势在于**修炼速度快、爆发强、稀有掉落概率高**，但**风险也高**（可能走火入魔、被正派围剿、声望受损）。

> 玩家可自行选择/发展门派的正魔倾向（具体选择机制待细化）。**正魔两道影响场景设定与角色解锁顺序，对应「一正一反」两条故事线。**

**双目标**

- **个人**：从落魄小卒修成**武林高手**。
- **门派**：把衰败门派经营成**一流门派**。

**落魄开局**

玩家初入时，袖中世界破落凋零（门派衰败、江湖冷清）。唯有持续「劳作」，以手部活跃度化作内力，才能让世界重新繁荣。

## 2. 设计原则

1. **手环是增益，不是门槛**：鼠标主要用于菜单操作，核心玩法挂机自主演化；手环提供增益，无手环也能正常玩。
2. **活跃即内力**：手部活跃度是核心资源，直接转化为内力/世界能量与奖励品质（手部活跃度越高，增益越好）。
3. **轻量挂机，深度经济**：操作极简，但盲盒、收集与交易提供长期目标。
4. **长线活跃激励**：长时间保持高手部活跃度获得累进收益，鼓励「沉浸式长任务」。
5. **江湖自主演化**：AI 侠客有记忆、有故事、有社交，玩家观察与守护，而非事事操控（Smallville 精神）。
6. **观察为主，运营为辅**：核心乐趣是看侠客自主演化；玩家通过「门派资源 + 技能系统」做轻度经营，而非事事操控。
7. **桌宠陪伴，而非仪表盘**：常驻桌面角落像桌宠一样陪伴，状态用世界表现含蓄传递（世界繁荣、侠客活跃），不用数字条/报表打扰工作。

## 3. 核心玩法循环

**新手教程（新手门派）**：

```
键鼠操作（基线，手环可选增强）→ 手部活跃度(内力)供能 → 门派弟子修炼 → 成果换盲盒 → 开箱/养成
```

**主线（袖里乾坤）**：

```
【自动层】工作(手部活跃度) → 内力供能 → AI侠客自动闯荡江湖(地区/难度) → 累计收益 + 产出盲盒/奇遇/江湖轶事
【Boss层】玩家鼠标主动打 Boss → 高价值掉落
【运营层】产出 → 门派资源(内力/灵石/声望) → 玩家升级随机获取的功法(心法/武学/阵法，分正魔两道) → 强化产出/解锁新内容
【交易层】盲盒物品 → 真实市场 → 钱币 / 实际收益
```

循环说明：

- **自动层**：玩家戴手环工作，手部活跃度实时化为「内力」，灌注袖中江湖；内力越足，AI 侠客自动闯荡江湖越快。江湖分**地区与难度**，侠客**强度**决定能否闯过、以及掉落品质，产出盲盒/奇遇/江湖轶事。
- **Boss 战**：江湖各地区深处有 Boss，玩家用**鼠标**主动操作战斗（点击/招式/走位），击败获得高价值奖励。
- **运营层**：侠客产出同时积累**门派资源**（内力/灵石/声望）。玩家把资源投入两条线：① **技能系统**（升级已获得的秘籍，提供气运流转速度倍率）；② **被动收益系统**（建筑/产业自动产出资源）。形成「产出 → 投入技能/被动 → 更强产出」的经营正循环。
- **交易层**：盲盒物品进入真实市场交易，换取钱币或实际收益。
- 长任务中持续保持高手部活跃度，江湖繁荣与奖励倍率逐级提升。

## 5. 玩法场景

> 场景格式：场景背景 → 玩家行为 → 手环反馈 → 游戏结果。

### 场景 0：新手教程——新手门派

- **背景**：新玩家进入游戏（**手环可选，非通关必备**），置身一个简陋的「新手门派」。
- **玩家行为**：跟随引导招收第一位弟子，通过**键鼠操作**（打字/点按）产生手部活跃度（佩戴手环为可选增强）。
- **手环反馈**：手部活跃度化为「内力」，灌注门派，弟子修炼产出「心得」。
- **游戏结果**：学会「手部活跃度 → 内力供能 → 修炼 → 盲盒」的基础循环；完成教程后解锁「袖中江湖」上帝视角。

### 场景 1：首次进入与手环连接

- **背景**：玩家首次启动游戏，准备佩戴肌电手环。
- **玩家行为**：佩戴手环（默认左手），连接设备。
- **手环反馈**：系统检测 sEMG + IMU 信号质量（**demo 用固定阈值，无需校准**）。
- **游戏结果**：连接成功后进入新手教程（新手门派）。

### 场景 2：进入袖中江湖（默认上帝视角）

- **背景**：玩家完成门派教程，进入默认的**上帝视角（闯关视角）**，俯瞰袖中江湖全景。
- **玩家行为**：观察江湖全貌，认识第一批 AI 侠客。
- **手环反馈**：世界通过繁荣度/侠客活跃度**含蓄体现**内力（不做数字条）。
- **游戏结果**：正式进入主线「袖里乾坤」玩法。

### 场景 3：手部活跃度（内力）供能，江湖兴盛

- **背景**：玩家戴手环进入长时间工作（如写代码、写文档、大量打字点鼠标）。
- **玩家行为**：保持手部活跃，持续为江湖灌注内力。
- **手环反馈**：内力上升，侠客更活跃、更强大，修炼与奇遇增加。
- **游戏结果**：**累计收益**（钱币/资源）持续积累，江湖繁荣度提升，获得更高品质盲盒/奇遇。

### 场景 4：AI 侠客自主修炼与恩怨情仇

- **背景**：袖中江湖的侠客拥有记忆、计划与社交关系（类 Smallville）。
- **玩家行为**：工作间隙瞄一眼江湖，观察侠客修炼、闯荡、切磋与事件。
- **手环反馈**：手部活跃度波动可能触发侠客的顿悟/随机事件。
- **游戏结果**：侠客自主发生故事（结缘、结怨、论剑、奇遇），产出江湖轶事与奇遇，玩家获得情感连接。

### 场景 5：获得盲盒并开箱

- **背景**：侠客历练/门派产出盲盒宝箱（**盲盒奖励，需查看并开启**）。
- **玩家行为**：用**鼠标点击**开箱。
- **手环反馈**：手部活跃度提供稀有度加成（越高越容易出稀有）；动画展示稀有度揭晓。
- **游戏结果**：开出秘籍、装备、丹药等，进入背包。

### 场景 6：真实市场交易

- **背景**：玩家背包中有可交易物品。
- **玩家行为**：用**鼠标**上架物品、设定价格、确认交易。
- **手环反馈**：无手环操作。
- **游戏结果**：出售获得钱币；稀有物品交易可获得实际收益。

### 场景 7：长任务与手部活跃度累进收益

- **背景**：玩家进行长时间挂机任务（数十分钟至数小时工作）。
- **玩家行为**：持续保持手部活跃，活跃时长不断累积。
- **手环反馈**：系统按活跃时长提升江湖繁荣度与奖励倍率，并实时展示收益变化。
- **游戏结果**：长任务中**累计收益**持续积累；结束时按活跃表现结算更高品质奖励，形成「越活跃越有回报」的正循环。

### 场景 8：门派资源运营（点技能树）

- **背景**：江湖产出积累了一批门派资源（内力/灵石/声望）。
- **玩家行为**：用**鼠标**打开门派面板，把资源投入**已获得的技能**升级（如升级「心法·吐纳」提升内力转化效率）。
- **手环反馈**：无手环操作（手环只做增益）。
- **游戏结果**：门派产出提升、解锁新侠客或新事件，形成「产出 → 点技能 → 更强产出」的经营正循环。

### 场景 9：挂机招募角色

- **背景**：挂机过程中，江湖里出现了可招募的角色（如流浪侠客、落魄弟子前来投奔）。
- **玩家行为**：用**鼠标**查看角色信息（资质/性格/背景），决定是否招募。
- **手环反馈**：无手环操作（手环只做增益）。
- **游戏结果**：招募成功，角色加入门派，参与自主演化与产出。

### 场景 10：Boss 战（选择关卡）

- **背景**：队伍闯荡到某地区深处，遇到 Boss。
- **玩家行为**：用**鼠标**选择要挑战的 Boss 关卡（战斗自动进行）。
- **手环反馈**：无手环操作（手环只做增益）。
- **游戏结果**：击败 Boss 获得高价值奖励（稀有盲盒/秘籍/装备/丹药）。

## 6. 交互与肌电映射

**核心原则：鼠标主要用于菜单操作，肌电手环为辅助增益。**

- 核心玩法由 AI 侠客**自主演化**，玩家主要用**鼠标做菜单操作**（开箱、交易、查看、管理），不戴手环也能玩。
- 手环只做**辅助增益**，不承担必需操作，避免信号不稳导致卡操作。
- **延迟约束**：手环控制延迟约 0.5s——适合连续增益（内力灌注），不适合离散指令（确认/点选），因此指令全部交给鼠标。

手环信号（极简，方向已定）：

| 信号 | 类型 | 用途 | 是否必需 |
|------|------|------|----------|
| **手部活跃度**（操作速度 + 手腕输入频率） | 连续 | 世界繁荣度/气运流转速度、奖励品质加成（核心增益） | 是（唯一必需信号） |

- **测量思路**：由**操作速度**（键盘/鼠标点击频率）+ **手腕输入频率**（sEMG/IMU，默认戴左手）共同计算，映射为**世界繁荣度与气运流转速度**（越高侠客演化越快、奖励越好）。气运流转速度 = **基准值 × 倍率 × 活跃度因子**：基准值随成长提升（pro 快于新手），倍率由技能/门派升级提供（乘算，不提高上限），活跃度因子封顶。demo 阶段用**固定阈值**，不校准；后续可引入个人基线。
- 手环支持**手势识别**（如握拳/张手/点指等）：demo 阶段先不用，只接入「手部活跃度」，手势留作后续扩展。

## 7. 经济系统（待完善）

- **两类奖励**：
  - **累计收益**：挂机自动积累（钱币、内力、灵石、声望），无需操作。
  - **盲盒奖励**：历练/击败 Boss 概率掉落，需查看并手动开启（秘籍、装备、丹药）。
- **盲盒内容**：秘籍、装备、丹药等（由侠客历练获得）；主线上还包括「奇遇」「江湖轶事」。
- **技能获取与升级**：
  - **通用技能点**：投入技能点提升**钱币/经验获取**等产出（类 TBH 升级系统）。
  - **通用技能**：基础技能，可在门派/商店**直接购买**（随便买）。
  - **稀有秘籍**：靠历练/盲盒/奇遇**随机掉落**，**一次性、可交易**（学习即消耗，可「学 or 卖」）。
  - 技能分**正道/魔道**两派；获取后投入内力/灵石升级。
- **装备（两类）**：
  - **通用装备**：基础装备，可在**钱币商城**直接购买。
  - **稀有装备**：历练/盲盒掉落，部分带**特殊词条**，可在**真实市场**交易。
- **门派资源（投入方向：技能 + 被动收益）**：
  - 内力：由手部活跃度持续转化，用于门派供能/技能升级
  - 灵石：由侠客修炼/产出积累，用于解锁武学/建筑
  - 声望：由奇遇/江湖事件积累，用于解锁高级内容
  - **投入方向**：① 技能系统（升级秘籍）② 被动收益系统（**基础设施**：建筑/产业自动产出资源，可升级）——设计目的是**吸引玩家偶尔回来操作一下**。
- **货币**：
  - 钱币（游戏内流通，用于日常交易与养成）
  - 稀有物品的实际收益（自由市场交易所得）
- **货币兑换**：**灵石 ↔ 钱币 按比例换算**（具体比例与机制待定：固定汇率 / 浮动汇率）。
- **两种交易体系**：
  - **钱币商城（系统商店）**：系统定价，用钱币购买通用技能、基础装备等（随便买）。
  - **真实市场（玩家自由市场）**：玩家间交易稀有物品（稀有秘籍、带特殊词条的装备、丹药），供需定价，可换钱币或实际收益（需考虑合规与提现规则）。
- **价值驱动**：稀有度 + 手部活跃度获取难度 + 市场供需。
