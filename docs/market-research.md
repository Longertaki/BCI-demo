# 袖里乾坤 市场调研

> 版本：v0.4 ｜ 状态：已联网核实（2026-08 检索，数据来源见文末）
> 说明：本版基于 Serper 联网搜索整理，关键结论已附来源链接；市场数字跨机构差异大，引用时需谨慎。
>
> **重要更新（2026-08）**：输入设备已从脑机接口（EEG/BCI）切换为**肌电手环（EMG）**。本文「脑电增益 / 脑活跃度」相关结论可迁移为「**肌电增益 / 手部活跃度**」（如「脑活跃度 = 世界能量」→「手部活跃度 = 世界能量」）；竞品拆解与市场规模部分仍然有效。故事主题已从「脑世界」改为「手作世界」，详见 game-design.md。

## 1. 调研目的与核心结论

为袖里乾坤的**玩法场景**提供依据，找出与 Taskbar Hero（TBH）的差异化方向。

**核心结论（重要，已根据实查修正）**：

1. TBH **已经有「宝箱掉落 + 交易船市场」**——所以「盲盒 + 市场」对我们不是差异化，而是**标配**；真正的差异化在 **脑电增益 + 办公族/科研题材 + 经济系统稳定性**。
2. 你说的「挂机课题组研究」几乎可以确定是爆款 **《导师模拟器》（Professor Simulator: Desktop Lab）**——它已经验证了「科研经营 + 桌面小窗口挂机」题材，但**没有脑机元素**。
3. 「任务栏/桌面角落挂机」正在成为品类趋势（Rusty's Retirement 等），我们切的是趋势内 + 脑机接口的空白交叉点。

## 2. 参考游戏拆解（已联网核实）

### 2.1 Taskbar Hero（TBH）

- **Steam 应用**：3678970，免费开玩。
- **热度**：曾约 **16 万同时在线**（YouTube 视频标题，待进一步核实）。
- **内容**：像素挂机 RPG，共 **120 关 = 3 个章节（Acts）× 10 关 × 4 种难度**，多职业/技能/装备。
- **核心机制（关键）**：
  - 角色挂机打怪 → **随机掉落宝箱**；
  - 玩家要**手动回来收菜、开宝箱**（每个宝箱固定出 1 个道具）；
  - 道具可做装备调整、合成，**放到「交易船」市场上架出售**；
  - **离线期间不掉宝箱**（只积累金币和经验）。
- **重大教训（5/30 负评爆发）**：玩家集中反馈「宝箱打不开 / 宝箱被系统吃掉 / 交易船不能用 / 道具被交易船吃掉」，官方回应是 **Steam 服务器无法负荷高频交易请求**。
- **对我们的启示**：
  1. 「掉落盲盒 + 玩家市场」TBH 已经做过，但**经济系统稳定性是它的翻车点**——这是我们做经济系统时必须重点设计的地方。
  2. TBH 需要玩家**手动回来收菜开箱**；我们可以用「脑活跃度」替代/增强这个「回来收菜」的钩子。

### 2.2 旅行青蛙

- **开发商**：日本 Hit-Point，2018 年爆红。
- **数据**：下载量破千万（**中国占 95%**）；上线初期安装量超 150 万。
- **玩法**：收集三叶草 → 换旅行道具 → 给青蛙打包行李 → 青蛙出门旅行 → 寄回明信片、带回特产 → 回家。
- **爆红原因（复盘）**：玩法简单、低压力、**心灵寄托/陪伴感**、佛系自传播、玩家代入「空巢青年」。
- **对我们的启示**：盲盒奖励可以做成「**角色归来带回特产/明信片**」的形式，带来惊喜感与情感连接；这正是方案 B 的来源。

### 2.3 导师模拟器（Professor Simulator: Desktop Lab）——「挂机课题组研究」

- **Steam 应用**：3894790（导师模拟器：桌面实验室）。
- **团队与成绩**：**4 人团队，3 天流水破 10 万**；早期文字冒险版已火出圈（「百万硕博集体翻身当导师」）。
- **定位**：**半挂机、小窗口运行的「科研主题桌面小搭子」**。
- **核心循环**：青年讲师 → 简陋实验室起步 → **招募学生 → 开展项目 → 发表论文 → 积累影响因子 → 申请项目 → 评职称晋升 → 学术大牛**。
- **玩法亮点**：成果驱动晋升、购置设备、制定规则、开组会、管理学生。
- **对我们的启示（极其重要）**：
  - 「科研/课题组经营 + 桌面挂机」题材**已被验证有市场**，且与我们的目标用户（办公族/程序员/硕博）高度重合。
  - 但它**没有脑机元素**——这就是我们的差异化切入点。

### 2.4 Rusty's Retirement 与「桌面角落挂机」趋势

- **Rusty's Retirement**：像素农场挂机游戏，**固定在屏幕底部/侧边**运行，自动种地。
- **媒体背书**：《纽约时报》2025/10 专题《These Video Games Want Only Some of Your Attention》报道桌面游戏趋势。
- **趋势确认**：2025 年「bottom-of-screen / taskbar」挂机游戏大量涌现，甚至出现 **Taskbar Treasures Week（12/8-12/15）** 主题活动。

---

### 2.5 上帝模拟器（God Simulator / WorldBox 等）

- **代表作品**：WorldBox - God Simulator（Steam 1206560）、Sandbox: God Simulator（Steam 2361370）、Creo God Simulator、经典《黑与白》（Black & White）等。
- **类型特征**：玩家扮演「世界管理员 / 上帝」，在沙盒中创造世界、投放生物、触发事件，**观察文明自主演化**，也可以随意摧毁。
- **WorldBox 特点**：创造/摧毁地形、投放羊/狼/兽人/精灵/矮人等生物、看文明建王国、殖民、造反、帝国兴衰；2025 年有大规模更新。
- **火的原因**：高自由度、想象力驱动、低压力、观察乐趣；「上帝视角 + 沙盘世界」在中国玩家中极具话题性（如「培养战犯」梗）。
- **对我们的启示**：
  - 「上帝照看世界 + 世界自主演化」天然契合**挂机 / 观察**形态——玩家工作间隙瞄一眼自己的世界。
  - 脑活跃度可以成为「神恩 / 世界能量」：**你的大脑就是这个世界的神**，这个隐喻与袖里乾坤主题高度契合。
  - 相比经营养成（方案 A），上帝模拟更强调**观察与创造**，情感连接与话题性更强。

---

### 2.6 生成式智能体：斯坦福小镇（Smallville）与 Simile

- **Smallville（斯坦福小镇）**：2023 年论文《Generative Agents: Interactive Simulacra of Human Behavior》（arXiv 2304.03442），第一作者即 **Joon Sung Park（朴俊成）**。
- **内容**：把 **25 个生成式 AI 智能体**放进像素小镇，每个智能体拥有**记忆流、计划、反思**，会起床、做早餐、上班、社交，甚至**自发组织了一场情人节派对**。
- **意义**：被广泛比作《西部世界》，是 2023 年最受关注的 AI Agent 实验之一，已开源（github.com/joonspk-research/generative_agents）。
- **Simile 公司**：朴俊成（CEO）联合 Michael Bernstein、Percy Liang 创办的「AI 模拟公司」，把 Smallville 的研究商业化。
- **核心业务**：为企业打造「**AI 替身消费者**」，在决策落地前先用替身跑模拟，预测真实用户反应；强调「让 AI 学会像人一样犯错」、因果数据、反事实推理。
- **融资**：约 14 个月累计募资 **3 亿美元级别**，B 轮 2 亿美元、估值 20 亿美元；投资人包括李飞飞、Karpathy、Bain Capital、Sequoia 等。
- **对我们的启示（关键）**：
  - Smallville 证明「**AI 智能体小镇自主演化**」魅力极强——用户会像看剧一样观察居民的日常生活与社交故事。
  - 上帝模拟（WorldBox）提供「观察 + 掌控世界」的框架，Smallville 提供「**有记忆、有故事、有社交的居民**」，两者结合正是「脑世界」最理想的形态。
  - 我们的差异化：**用玩家的脑活跃度给这个小镇供能**——这是 Smallville / Simile / WorldBox 都没有的「人类大脑作为世界能量源」设定。

## 3. 市场规模数据（附来源，数字跨机构差异大）

- 2024 年中国游戏市场规模 **3257.8 亿元**（+7.53%）。
- 2025 年 **3507.89 亿元**（+7.68%），用户规模 **6.83 亿**。
- 小程序游戏 2024 年约 **398 亿元**，2022-2024 年复合增长率 **182.3%**。

### 3.2 BCI 相关市场
> 注意：不同机构口径差异极大，以下仅供量级参考。

- **BCI 游戏市场**：2025 年约 **21 亿美元** → 2034 年预计 **98 亿美元**，CAGR 18.6%（DataIntelo）。

## 4. 差异化机会（修正版）

| 维度 | Taskbar Hero | 导师模拟器 | **袖里乾坤** |
|------|--------------|-----------|------------------|
| 挂机形态 | 任务栏战斗 | 桌面小窗口经营 | 桌面角落挂机 |
| 题材 | 像素英雄冒险 | 科研/课题组经营 | 办公族/程序员「脑力世界」 |
| 核心驱动 | 自动战斗+掉落 | 自动科研产出 | **工作脑活跃度 → 增益** |
| 经济 | 宝箱+交易船（翻车） | 较弱 | **盲盒+金币市场+实际收益市场（需稳定）** |
| 脑机 | 无 | 无 | **有（差异化核心）** |

**结论：我们的差异化不是「挂机」也不是「盲盒+市场」，而是「脑电增益 × 办公科研题材 × 稳定经济系统」的交叉。**

## 5. 四个候选场景方案（结合调研修正）

> 公共底座：挂机 + 脑活跃度增益 + 盲盒 + 市场。

### 方案 A：脑力研究所（课题组经营向，对标导师模拟器 + BCI）

- **一句话**：经营「脑力研究所」，脑活跃度供能，研究员自动产出成果 → 成果换盲盒 → 升级研究所。
- **差异化**：导师模拟器验证了题材，我们加上 **BCI 脑活跃度驱动产出** + **盲盒经济**。
- **核心循环**：工作（脑活跃度）→ 研究所产出 → 成果兑换盲盒 → 开箱/交易 → 升级解锁新方向。
- **脑电映射**：脑活跃度 = 研究所效率；活跃度波动 = 随机产出事件。

### 方案 B：脑际旅人（旅行青蛙向）

- **一句话**：派遣角色进「脑世界」探险，回来带回盲盒与「明信片/故事碎片」。
- **差异化**：陪伴感 + 被动收集；把旅行青蛙的「特产」升级为可交易的盲盒。
- **核心循环**：工作（脑活跃度）→ 决定探险品质 → 归来带盲盒/明信片 → 收集/交易。
- **脑电映射**：脑活跃度 = 探险品质/稀有掉落；任务切换 = 奇遇事件。

### 方案 C：挂机闯关 + 盲盒市场（TBH 进化版）

- **一句话**：经典挂机闯关，脑活跃度加速推关，掉落盲盒，自由市场交易。
- **差异化**：TBH 的盲盒+交易船已存在且翻车；我们做**稳定的经济系统 + BCI 增益**。
- **核心循环**：挂机战斗（自动）→ 脑活跃度加速 → 通关得盲盒 → 开箱 → 市场交易。
- **脑电映射**：脑活跃度 = 攻速/爆率/奖励品质。

---

### 方案 D：脑界主宰（上帝模拟器 × 斯坦福小镇向）

- **一句话**：你是「脑世界」的上帝/守护者，世界里的 AI 居民（类 Smallville）**自主生活、社交、演化**，你的脑活跃度为世界供能，居民产出盲盒与「神迹故事」。
- **差异化**：把 WorldBox 的「观察 + 掌控」、Smallville 的「有记忆有故事的生成式智能体」、BCI 的「脑活跃度供能」三者合一——这是所有竞品都没有的设定。
- **核心循环**：工作（脑活跃度）→ 世界供能 → AI 居民自主生活/社交/创造 → 产出盲盒/神迹/故事碎片 → 收集/交易/改造世界。
- **脑电映射**：脑活跃度 = 世界能量/繁荣度；活跃度波动 = 居民灵感/随机事件；任务切换 = 投放新居民/触发剧情。
- **适合**：喜欢观察、收集与「养一个世界」的办公族/程序员，追求强话题性与情感连接。

## 6. 初步建议（结合调研修正）

- **两个强候选**：
  - **方案 A（脑力研究所）**：题材已被《导师模拟器》验证，用户代入感强、长线养成清晰；叠加 BCI 脑活跃度与盲盒经济后差异化明确。
  - **方案 D（脑界主宰）**：差异化最强、BCI 隐喻最贴（「你的大脑 = 世界之神」）、传播话题性高，且与「观察式挂机」天然契合；再叠加斯坦福小镇式「有记忆、有故事、有社交」的生成式智能体居民，魅力最强。
- **融合可能**：A 与 D 并不冲突——可以做成「你的脑活跃度供养一个小镇，镇里有研究所与一群 AI 居民自主生活、演化」，兼顾经营深度、上帝视角观察与角色故事。
- **方案 B（脑际旅人）** 可作为奖励发放方式（居民/角色归来带盲盒/神迹）。
- **方案 C（挂机闯关）** 可作为世界内的战斗/闯关副本。
- **必做的工程/设计重点**（吸取 TBH 教训）：经济系统的**交易稳定性、离线收益规则、防刷与合规**，绝不能重蹈 TBH「交易船崩了」的覆辙。
