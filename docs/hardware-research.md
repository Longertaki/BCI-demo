## 1. 产品线概览

唯理科技（苏州，Waveletech）是国内少数拥有**自研生物电芯片**（WLS128）的神经传感厂商，产品覆盖心电/脑电/肌电。腕带类产品主要有：

| 版本 | 通道 | 定位 | 价格 | 通信 |
|------|------|------|------|------|
| 消费版「神经腕带」 | 8/16 ch sEMG | 手势遥控（HID 设备） | 约 980 元 | BLE HID |
| 科研/二次开发版 | 8 ch sEMG | 科研与手部数据采集 | $217（Tindie） | BLE / 有线 |
| 科研版（18 通道） | 18 ch EMG | 科研、手势算法开发 | 需询价 | 有线 → 蓝牙接收器 |

> 关键区别：**消费版走 BLE HID 协议（连接即用，像鼠标键盘一样），只输出手势事件；科研/开发版提供原始 sEMG + IMU 数据接口，可做二次开发。**

## 3. 开发者接口

- **消费版（HID）**：BLE HID 协议，连接即用、无需装 APP；只能拿到**手势事件**（单击/双击/捏合/拖动等），不适合做连续「活动量」分析。
- **科研/开发版（原始数据）**：提供**原始 sEMG 数据流 + IMU 数据**，支持 SDK 扩展与数据格式导出；可用于自己计算手部活动量、训练手势识别模型。
- **官方文档入口**：
  - 产品介绍页：https://waveletech.com/solution-articles/emg/emg_bihuan/
  - Tindie 购买页（含 Datasheet）：https://www.tindie.com/products/waveletech/waveletech-emg-wristband-neuro-armband-for-emg/

## 5. 对我们的选型建议

**结论：我们要买/用的是「科研/二次开发版」，而不是 980 元的消费版。**

原因：
1. 我们的核心信号是**连续的手部活跃度**（打字、点按、移动的活动量），需要**原始 sEMG 数据流**做 RMS/包络/活动量计算；消费版 HID 只给离散手势事件，给不了连续活动量。
2. 8 通道 + 2000 sps 对「活动量计算」**绰绰有余**（sEMG 有效频段约 20–500 Hz）；8 通道甚至足以支持后续手势识别。
4. **延迟约 0.5s**：对「手部活跃度 → 内力」这类**连续增益**完全无感；但对**离散指令**（手势点选/确认）太慢。因此交互设计坚持「鼠标做菜单/指令，手环只做增益」是正确的。
3. 官方 SDK + 原始数据接口能让我们把「sEMG → 手部活跃度 → 内力」这一步完全掌控在本地。

**推荐采购**：Tindie 科研版（$217，8 通道，含 Datasheet）或直接找官方拿开发版 SDK。

---

## 6. 需要向官方确认的问题清单

1. **开发版 SDK 的下载方式与支持平台**（Windows / Linux / Python / C++）？
2. **原始数据格式**：sEMG 各通道是否实时开放？采样率 250 还是 2000 sps 可调？IMU 是否同步输出？
3. **数据接口**：有线（USB 串口？）还是 BLE 透传？延迟大概多少？
4. **开发版价格与购买流程**（国内是否直接发货）？
5. 是否提供**示例代码 / 数据解析 Demo**（波形绘制、数据导出）？
6. 端侧是否也输出**活动量/手势**结果（可在原始数据之外备用）？
