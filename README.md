# 袖里乾坤

> 掌中小世界 · 一款基于肌电手环（EMG）的交互式挂机游戏项目。
> 玩家的手部活跃度（打字、点按、移动等）将实时转化为游戏中的增益。

---

## 一、项目简介

**袖里乾坤** 旨在探索「肌电信号 → 游戏交互」的完整链路：通过可穿戴肌电手环采集实时 sEMG（表面肌电）+ IMU（惯性测量）信号，经过信号预处理与活动量计算，将手部活跃度、手势等信号转化为游戏中的增益，让玩家「用双手的忙碌程度玩游戏」。

这是一个横跨 **信号处理、机器学习、生成式 AI 与游戏开发** 的交叉项目，既可以作为肌电交互技术的演示平台，也可以发展为面向办公族/程序员的「工作投入即收益」的挂机游戏。

**核心目标用户**：长期对着电脑工作的**办公族**与**程序员**。游戏以任务栏挂机形态常驻桌面，工作时佩戴肌电手环，手部活跃度自然转化为游戏增益——「工作越投入，游戏奖励越好」。

---

## 二、项目目标

- **核心目标**：建立一条从 sEMG 原始信号到游戏实时增益的可用闭环。
- **技术目标**：
  - 完成肌电手环的接入与信号采集（sEMG + IMU）。
  - 完成滤波、活动量计算与手部活跃度估计。
  - 实现低延迟、稳定的信号-游戏通信接口。
  - 提供可视化的信号质量监控与游戏反馈。
- **体验目标**：
  - 让玩家直观感受「手越忙，增益越好」。
  - 通过游戏化反馈帮助办公族/程序员把工作投入转化为游戏奖励。

---

## 三、游戏玩法

袖里乾坤 是一款借鉴 Taskbar Hero 的挂机游戏，以鼠标操作为主，肌电手环提供辅助增益。

- **主线「袖里乾坤」**：你是袖中藏着一方江湖的世外高人，AI 侠客（类斯坦福小镇）自主修炼、闯荡、切磋；手部活跃度化为内力灌注江湖，活跃度越高江湖越兴盛、奖励越好。
- **新手教程「新手门派」**：先经营一个小门派，学会「手部活跃度 → 内力供能 → 修炼 → 盲盒」的基础循环，再解锁袖中江湖。
- **挂机形态**：任务栏/桌面角落常驻，不打断工作；不戴手环也能挂机（手环是增益而非门槛）。
- **交互方式**：鼠标主要用于菜单操作（开箱、交易、查看、管理），核心玩法挂机自主演化；手环辅助增益（手部活跃度 = 内力）。
- **奖励与经济**：侠客历练产出盲盒，开出秘籍、装备、丹药等；可在钱币市场与实际收益市场交易。
- **核心目标**：提升手部活跃度/工作投入——长任务中手部活跃度越高，收益与奖励越好。

## 四、系统架构

```
┌──────────────┐  原始sEMG+IMU  ┌──────────────┐   活跃度/手势   ┌──────────────┐
│  肌电手环     │ ─────────────▶ │  信号处理层   │ ─────────────▶ │   游戏引擎    │
│ (唯理EMG+IMU)│                │ 滤波/活动量/  │               │ (Unity/Godot/ │
└──────────────┘                │ 手势识别(可选)│               │  Pygame/Web)  │
                                └──────────────┘               └──────────────┘
                                       ▲                               │
                                       │        实时反馈(视觉/听觉)       │
                                       └───────────────────────────────┘
```

- **采集层**：负责与肌电手环通信（SDK / BLE），获取 sEMG + IMU 数据流。
- **信号处理层**：滤波、去运动伪迹、活动量计算、手部活跃度估计、手势识别（可选）。
- **通信层**：将处理结果以低延迟方式（WebSocket / OSC / 本地 IPC）推送给游戏。
- **游戏层**：将手部活跃度映射为世界能量与交互。
- **监控层**：实时展示信号质量、活跃度曲线，便于调试与演示。

## 八、风险与注意事项

- **信号噪声**：运动伪迹、手环佩戴松紧、电极接触不良会影响信号质量。
- **个体差异**：不同人的手部肌肉信号差异大，需要基线校准。
- **肌肉疲劳**：长时间使用可能导致疲劳，需注意舒适度设计。
- **延迟要求**：游戏交互要求低延迟，需权衡信号窗口长度与实时性。
- **安全合规**：涉及生理数据采集，需注意数据隐私与伦理合规。
- **健康提醒**：本项目为研究与娱乐用途，不构成医疗诊断。
